# HR Recruitment Information System Analysis

## Project Overview

This project presents a business and information system analysis of a proposed **HR Recruitment Information System** for a fictional organization, **NovaTech Solutions**.

The project analyzes the organization's existing recruitment process, identifies key operational problems, and proposes a centralized information system designed to improve recruitment efficiency, data management, communication, and decision-making.

The project demonstrates how a business process can be analyzed and transformed into a structured information system solution.

---

## Business Problem

The existing recruitment process relies heavily on manual activities such as emails, spreadsheets, individual documents, online job platforms, and separate communication channels.

This creates several challenges, including:

* Fragmented candidate information
* Manual application screening
* Limited visibility of candidate status
* Difficult interview coordination
* Decentralized interview feedback
* Duplicate data entry
* Communication gaps
* Time-consuming recruitment reporting
* Increased risk of data inaccuracies

---

The proposed system aims to:

## Current Recruitment Process

The current recruitment process was analyzed to identify how recruitment activities are performed and where inefficiencies occur.

The **As-Is Process Flowchart** documents the existing workflow from identifying a staffing requirement through candidate hiring.

Key stages include:

1. Staffing requirement identification
2. Recruitment request
3. Request approval
4. Job vacancy preparation
5. Vacancy publication
6. Application collection
7. Application screening
8. Candidate shortlisting
9. Interview scheduling
10. Interview evaluation
11. Candidate selection
12. Job offer
13. Candidate hiring

## Proposed Information System

The proposed **HR Recruitment Information System** provides a centralized platform for managing the recruitment lifecycle.

The system supports multiple users, including:

* Candidates
* HR Recruiters
* Hiring Managers
* Interviewers
* HR Managers / Administrators

### Core System Functions

* Candidate profile management
* Job vacancy management
* Recruitment request management
* Online application management
* Candidate screening and shortlisting
* Interview scheduling
* Interview feedback management
* Candidate status tracking
* Job offer management
* Recruitment notifications
* Recruitment reporting and analytics
* Role-based access control

---

## To-Be Recruitment Process

The proposed To-Be process introduces greater automation and centralized data management.

The improved workflow includes:

**Recruitment Request → Approval → Vacancy Creation → Application → Screening → Shortlisting → Interview → Evaluation → Selection → Job Offer → Hiring → Onboarding**

The proposed process reduces dependence on disconnected spreadsheets, emails, and manually maintained records.

## Database Design

The proposed database uses a relational structure to organize recruitment information.

Key relationships include:

* One department can have multiple recruitment requests.
* One candidate can submit multiple applications.
* One job vacancy can receive multiple applications.
* An application can lead to interviews.
* Interviewers can provide interview feedback.
* An application can result in a job offer.
* Employee users can be associated with departments and recruitment activities.

Primary and foreign keys are used to maintain relationships and data integrity.
